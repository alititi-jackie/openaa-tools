Standard、REAL ID、Enhanced 怎么选？

回答几个生活化问题，看看哪一种纽约驾照 / ID 更适合你。

① 你是美国公民吗？
② 你想直接用这张驾照 / ID 坐美国国内飞机吗？
③ 你需要从加拿大、墨西哥等地经陆路 / 海路返回美国吗？
④ 你能证明美国公民身份或符合 REAL ID 要求的 lawful status 吗？
完成上面选择后，这里会给出建议。

三种证件简单理解

Standard

主要就是开车。它本身不能作为联邦 REAL ID 用途证件；坐美国国内飞机时，需要使用护照等 TSA 接受的其它身份证件。

REAL ID

适合希望直接用纽约驾照 / ID 坐美国国内飞机、进入需要 REAL ID 的联邦设施的人。纽约 DMV 对 REAL ID 不收额外升级费，但正常办证费用仍适用。

Enhanced

仅美国公民可申请。包含 REAL ID 用途，并增加特定加拿大、墨西哥和部分加勒比地区陆路 / 海路返美功能；纽约 DMV 额外收费 $30。

华人最容易误解的几个地方

Standard 不是“不能坐飞机”

准确说，是 Standard 驾照本身不能作为 REAL ID-compliant 的机场身份证件。TSA 仍接受其它证件，例如有效美国护照、外国政府签发护照、绿卡和符合要求的 EAD 等。

有护照，不一定急着办 REAL ID

如果你愿意在美国国内旅行时携带 TSA 接受的护照或其它证件，Standard 仍可以满足普通驾驶用途。REAL ID 的主要便利，是不用为了这些联邦用途另外带护照。

Enhanced 不是“更高级就一定更好”

Enhanced 最有价值的额外功能，是符合条件的美国公民可在特定情况下从加拿大、墨西哥和部分加勒比地区经陆路或海路返回美国。它不能代替护照用于这些国家之间的国际航空旅行。

非美国公民也可能办 REAL ID

Enhanced 只限美国公民，但 REAL ID 并不只限美国公民。符合纽约 DMV lawful status 文件要求的非公民也可能申请；如果你不确定自己的移民文件是否符合，可以使用本站 REAL ID 检查。
