资格通过以后，再考虑用途

Standard 用于普通驾驶，不能作为联邦 REAL ID 用途的州证件。REAL ID 可用于美国国内乘机及特定联邦用途；正常办理费用仍适用，没有额外 REAL ID 升级费。TSA 也接受有效外国护照、绿卡等替代证件，出行前核对 TSA 清单。

Enhanced 仅符合条件的美国公民可办；符合联邦 REAL ID 用途，还可用于从加拿大、墨西哥和部分加勒比国家经陆路 / 海路返美。它不能代替国际航空旅行所需护照；目的地入境要求仍需另查。Enhanced 额外收费 $30。

哪些情况不能简单判断？

EAD 本身不是 REAL ID lawful status 的充分证明；须配合 DHS 文件明确证明 6 C.F.R. 37.3 所指的合格身份。外国护照没有配套移民文件，可在普通驾照规则下用于出生日期，不得因此判定符合 REAL ID。

Green Light Law 适用于16岁及以上纽约居民申请普通非商业驾照 / Permit，不要求证明 lawful status；不适用于 Non-Driver ID 或商业驾照。这里仅检查材料，不代表已完成年龄、视力、笔试或路考条件。
