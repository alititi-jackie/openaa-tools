纽约 DMV 6 Points 是什么？

第一次申请纽约州 Standard Learner Permit、Driver License 或 Non-Driver ID 时，DMV 会按可接受文件核对姓名、出生日期和身份，并要求 Proof of Name 达到规定积分。这个工具把复杂表格整理成“身份证明 → 纽约地址证明 → 其它加分证明”三步，方便刚来美国的华人快速检查自己手上的材料。

中国护照可以用来申请纽约驾照吗？

外国护照必须符合纽约 DMV ID-44 对应条件。常见情况是护照同时配有符合要求的美国移民文件，例如有效 Visa 与 I-94 等。只有一本外国护照时，不应直接把它当成完整的 4 分组合。

纽约考驾照一定要有 Social Security Card 吗？

不一定。没有 SSN 的申请人也可能按 DMV 规定办理 Standard 证件，但必须按自己的实际情况完成相应声明或证明。社安卡如果符合要求，可以作为 Proof of Name 的计分文件。

银行账单是不是必须的？

不是。银行账单只是常见的纽约地址证明之一。工资单、符合要求的 Utility Bill、W-2 等也可能用于证明当前纽约州地址。页面不会强制要求你一定有银行卡或银行账单。

为什么已经 6 分还可能不够？

6 Points 与地址证明不是同一个条件。即使身份和其它加分证明已经达到 6 分，如果没有符合要求的纽约州地址证明，主要材料仍没有准备齐。Standard 通常至少需要一份符合要求的纽约州地址证明。

同一家银行的文件能重复算吗？

纽约 DMV 有 One Proof Per Source or Type 的限制。同一种证明或同一来源的多份材料不能简单重复使用。工具会避免已知的同类型文件重复计分；对于银行等来源信息网页无法知道的情况，会提醒你自行核对。

使用前注意

本工具面向 Standard Permit / Driver License 常见文件准备场景，主要用于快速自查，不代替 DMV 最终审核。REAL ID 和 Enhanced 的地址及身份要求更严格，请使用本站对应的 REAL ID 工具进一步检查。
