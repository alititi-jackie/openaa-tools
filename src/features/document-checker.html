给纽约华人的 DMV 文件准备说明

很多在纽约生活的华人第一次去 DMV 办 Learner Permit、驾照、Non-Driver ID 或 REAL ID 时，最容易卡在“文件不够”“地址证明不合格”“6 points 不够”“名字不一致”这几件事。OpenAA 工具库 提供这个 DMV 文件检查器，是为了让大家在出门前先用中文把材料大概核对一遍，减少白跑一趟 DMV 的机会。

纽约 DMV 的文件要求会根据你申请 Standard、REAL ID 还是 Enhanced 而不同。Standard 通常要求 1 份纽约地址证明；REAL ID 和 Enhanced 通常需要 2 份纽约地址证明。REAL ID 是用于美国国内航班和部分联邦设施的联邦合规证件；Enhanced 除了满足 REAL ID 类用途外，还可用于部分从加拿大、墨西哥和加勒比地区陆路或海路返回美国的场景，但 Enhanced 通常只限美国公民申请。

准备文件时，银行账单、水电账单、工资单、租约、纽约驾照或 Non-Driver ID 等都可能作为地址证明，但文件上的地址必须是当前纽约地址，电子账单通常需要打印。DMV 也可能不接受 P.O. Box 作为地址证明。名字如果因结婚、离婚或法院改名发生变化，需要准备能连接新旧姓名的正式文件。
