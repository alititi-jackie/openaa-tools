拖动滑杆选择长度（8–64 位），勾选需要的字符集，点击生成。点击结果区域即可把密码复制到剪贴板。

常见问题

多少位密码够安全？

包含大小写字母、数字和符号的 16 位密码约有 105 bit 熵，暴力破解在可预见的未来都不现实；重要账户建议 16 位以上，普通账户至少 12 位。

符号都包含哪些？

! @ # $ % ^ & * ( ) - _ = + [ ] { } ; : , . < > ? / ~，共 29 个，覆盖绝大多数网站允许的符号。

生成的密码会存下来吗？

不会。本工具不写本地存储、不发网络请求，密码只显示在页面上；请自行保存到密码管理器，刷新页面后无法找回。
