GPA 计算器

添加课程、填入成绩与学分，一键算出加权 GPA（标准美国 4.0 制）。

—添加课程并计算
采用标准美国 4.0 换算：A=4.0、A−=3.7、B+=3.3、B=3.0、B−=2.7、C+=2.3、C=2.0、C−=1.7、D+=1.3、D=1.0、F=0。不同学校算法可能有差异，结果仅供参考。

百分制 → GPA 快速换算

怎么用

选择成绩输入方式（百分制 / Letter / 绩点），逐行填写课程名（可空）、学分和成绩，点「计算 GPA」即可得到按学分加权的平均绩点。下方还有单科百分制快速换算。

常见问题

加权 GPA 怎么算？

每门课的绩点 × 学分，全部相加后再除以总学分。学分越高的课对 GPA 影响越大。

百分制和 Letter 是怎么对应的？

按标准换算：93–100 为 A（4.0）、90–92 为 A−（3.7）、87–89 为 B+（3.3）、83–86 为 B（3.0）、80–82 为 B−（2.7）、77–79 为 C+（2.3）、73–76 为 C（2.0）、70–72 为 C−（1.7）、67–69 为 D+（1.3）、63–66 为 D（1.0）、60 以下为 F（0）。

为什么和学校算的不一样？

不同学校算法有差异：有的不设 +/− 档、有的 A+ 按 4.3 算、有的荣誉/AP 课程加权到 5.0。本工具采用最通用的标准 4.0 制，结果仅供参考，请以学校官方算法为准。
