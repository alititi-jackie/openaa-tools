REAL ID 去 DMV 常见必备清单

1. 身份 / 出生日期 / 合法身份常见为美国护照、出生纸、绿卡、EAD、外国护照加有效身份文件等。
2. SSN 或不符合资格信有 SSN 的通常需要证明 SSN；没有 SSN 的合法身份申请人，可能需要 SSA 不符合资格信。
3. 两份纽约地址证明REAL ID / Enhanced ID 需要 2 份纽约州居住地址证明，P.O. Box 通常不接受。
4. 6 Points 身份证明纽约 DMV 很多驾照/ID 业务仍要按 6 Points 文件规则准备。

REAL ID、Enhanced、Standard 有什么区别？

REAL ID：用于美国国内飞机、进入部分联邦设施等联邦用途。纽约 DMV 说明，REAL ID 本身通常不额外收费，但需要到 DMV 现场提交文件并重新拍照。

Enhanced ID：也符合 REAL ID 联邦用途，并可用于从加拿大、墨西哥和部分加勒比国家经陆路或海路返回美国，但通常有额外费用。

Standard ID：普通纽约驾照 / ID，不一定符合 REAL ID 联邦用途。是否适合你，要看你是否需要坐美国国内飞机、进入某些联邦设施，或是否已有护照等替代证件。

去 DMV 前建议这样做

第一，先用本页做一次中文预检查；第二，再用纽约 DMV 官方 Document Guide 生成你的个人文件清单；第三，预约 DMV 后，把所有文件原件或官方认可版本带齐。不要只带手机截图，很多文件需要打印版或原件。
