# OpenAA工具库维护约定

站点为`tools.openaa.com`，品牌为OpenAA工具库。运行命令、注册数量、发布阶段和排查入口统一维护在[主README](../README.md)，工具注册表是`src/data/tools.json`。

## 公共导航与分类

公共页面通过BaseLayout接入GlobalNavigationButtons。返回优先浏览器后退；没有上一页时，内页返回首页，首页返回OpenAA主站。回顶在滚动超过900px时出现，弹窗、软键盘和打印避免遮挡。

首页直接显示注册工具，当前60个、7类：美国生活、日常生活、图片工具、DMV与证件、汽车出行、单位换算、工资与理财。分类顺序在`src/data/tools.ts`维护，`category`和`q`控制筛选，搜索后空组隐藏。旧`/tools/`目录页已删除，不提供兼容跳转。

## 数据导入与存储

记账/汇率导入先验证文件大小、全部记录、日期、有限金额、分类、重复ID与数量上限，成功后才写入。当前限制为5MiB、10000条。

导入前快照保存于原键追加`_before_import`的位置，仅保留一份；备份界面提供恢复按钮。快照失败则停止导入，不覆盖原数据。快照仍在本机，清理浏览器数据会同时删除快照，不能替代下载备份。

保留原存储键和备份格式。损坏或写入失败时不得用空数组覆盖未知记账/汇率数据；收藏/计算历史各有容错规则。测试使用隔离记录，不操作真实用户的本地数据。

## 时间与计算规则

时间换算按IANA时区往返匹配真实时刻：春季不存在的时间拒绝转换，秋季重复时间显示两个可能结果，不替用户擅自选择。

税率、DMV和其它专业规则独立对照官方来源，记录适用范围、年份和实际复核日期；部署或界面变化不能声称重新核实。测试校验当前实现和边界，不保证所有实际情境都被覆盖。

## SEO与内容

攻略来自两类注册数据，工具关联和主路径由`guides.ts`统一生成。`toolIds[0]`决定工具攻略主路径；更改顺序要考虑已有URL，避免重复内容和断链。新增文章检查H1、描述、canonical、FAQ可见内容、来源与sitemap。

当前postbuild不生成sitemap lastmod；以后若加入，必须使用真实内容更新时间，不使用每次构建时间代替。Search Console、Google选择的canonical和排名需独立验证，构建通过不能保证收录。

## 验证与发布

`npm run validate`包含Astro检查、Node测试、完整build和Python产物校验；浏览器测试另运行`npm run test:e2e`。测试应指向新构建的`dist/`，避免4321端口被旧服务占用导致误测。

CI还在部署后执行正式域名验收：检查release commit、全部攻略/DMV页面、metadata、sitemap与部分实际交互。供应商可用性、规则人工核验、全部离线生命周期仍不能由单次自动化覆盖。

离线升级分别检查三个工具worker的作用域、缓存前缀和旧浏览器会话。回滚不能清理用户记录；保留稳定URL、数据格式和恢复路径。
