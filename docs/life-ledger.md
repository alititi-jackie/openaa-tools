# OpenAA 生活收支账本 · 开发与交接记录

## 页面与交互约定

顶部沿用工具库 Logo、Go 导航与分享。下方横向吸顶导航固定为「开支、收入、汇款、汇总」，当前项高亮。首次打开默认开支。前三项各有且仅有「记一笔、查看、导出／分享」三张入口卡。新增默认本地当天，保存回当前账本首页；从明细编辑后返回原查询范围。删除前确认。

|账本|输入顺序|统计|
|---|---|---|
|开支|日期、美元金额、现金／银行卡、分类、备注|总额、现金、银行卡、笔数|
|收入|日期、美元金额、现金／银行卡、备注（选填）、取消／保存|总额、现金、银行卡、笔数|
|汇款|日期、美元、汇率、人民币、备注|汇出美元、人民币合计、加权平均汇率、笔数|

开支沿用购物、餐饮、交通、房屋、账单、其它六类。汇款一笔代表一次实际汇出。输入美元、汇率、人民币中的任意两项可算第三项；修改计算结果时保留较早的手输值，重算另一项。金额显示两位小数，汇率三位，实际保存的人民币参与汇总。新增和编辑均无「减去」操作。平均汇率 = 人民币总额 ÷ 美元总额。

## 查看及结余

每个查看页采用「月份、年度、汇总」。月份默认本月，允许手选；当月为空也能切到历史月份。年度默认今年，可切年份，按月列小计并能展开明细。汇总涵盖全部历史，按年份分组。明细从新到旧排列。取消按周查看。

顶部「汇总」直接显示收支总览，同样默认本月，可切年度或全部。三个账本使用同一期间。先计算收入减生活开支，再扣汇出美元；人民币单列。结果可为负数。期间不结转上期余额，「累计结余」涵盖所有日期。汇款不生成开支记录。例如收入 5000、开支 1800、汇出 1000、人民币 7200，应依次得到 3200、2200 和 ¥7200。

## 分享、备份、旧账

复制当前所选期间的汇总，下载或分享整个当前账本的 Excel、JSON；按钮写明范围。Excel 用于阅读与分享，JSON 用于恢复。新工具独立存储，初次打开为空。支持按账本导入，类型不符应拒绝。旧开支备份手动导入；旧汇率的新增记录先预览，用户勾选确实为汇款的条目，减去记录排除。合并同一份备份两次不能重复计数；覆盖前确认，并能恢复导入前记录。手机端复制必须有可见反馈，无法自动复制时提供手动复制文本。

## 2026-11-20 新增记录的必选项

新增开支的支付方式、开支分类和新增收入的收款方式初始均为空，每一笔均需重新选择。点击保存时，缺项旁显示对应的中文提示并阻止保存，已填写内容保留。编辑已有记录时回显原选项。

## 2026-11-20 收入备注

收入表单在收款方式下方显示选填备注。新增、编辑和明细共用现有备注字段，Excel 明细和 JSON 备份保留备注，历史无备注记录可继续使用。

## 2026-11-20 汇率核对

汇率低于 5.000 或高于 9.000 时显示橙色小字「⚠ 汇率可能有误，请核对。」手动输入在离开输入框时提示，自动换算后直接判断。保存时显示实际三位小数汇率，提供「返回修改」和「确认保存」。金额也异常时合并为一次确认。5.000 和 9.000 均在范围内，空白、零和负值按原校验处理。

## 2026-11-20 手机主屏幕入口

开支、收入和汇款首页三张卡片下方提供「添加到手机主屏幕」。安卓浏览器提供原生安装事件时直接调用，否则给出菜单步骤。iPhone 提示 Safari 分享菜单，微信提示先在系统浏览器打开。独立窗口启动时隐藏入口。桌面简称为「生活账本」，启动进入默认开支页。正式迁移后应从正式域名重新添加图标，并用 JSON 备份迁移试用账目。

## 2026-11-20 导出范围、完整备份和清空

此版本更新前文的分账导出规则。每个板块默认自己的范围。「全部记录」始终覆盖三个账本的所有年份。单账本 Excel 首页按查看页所选时段统计，附该本所有年份的明细、月度和年度统计；总览默认仅导出所选时段的六项结果。完整 Excel 按顺序列收支总览、开支明细、收入明细、汇款明细、月度汇总、年度汇总。各范围均可复制或分享摘要文字。全量 JSON 包含三个账本，预览逐本计数后合并或覆盖；校验、失败回滚及原单本和旧格式导入均需保留。

单本清空入口固定跟随所在账本。只有收支总览的「全部记录」提供三个账本一起清空。第一次点击核对实际笔数与范围，可先单独下载 JSON；确认后删除目标记录及导入前副本并更新统计。首页保留三张主卡，桌面添加说明随按钮隐藏，备份提醒与使用说明链接常驻。说明页永久路径 /usa/life-ledger/guide/，随账本缓存供离线阅读。正式迁移前用完整备份核对笔数与跨账本结余。

### 全部记录 Excel 与复制汇总文字修订

四个入口选择「全部记录」后，下载和分享均生成同一结构的一份 XLSX。收支总览、收支月度和年度汇总共三张，开支、收入和汇款各有汇总、明细、月度和年度四张，共十五张。各表直接写入计算好的数值；明细和分期表末行显示合计，汇款按实际记录分别累计美元及人民币。单本导出的首页使用选定时段，全部记录使用所有年份。恢复旧版「汇总文字」卡片与带时段的复制按钮，剪贴板文本按标题、逐行指标和数值排列。
