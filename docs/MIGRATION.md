# 迁移验收

基线：`ef0f96135868affb5ddc74f8ea27fc8bc7fc2b76`（main）。

## 范围

- 34 个 `/tools/` 工具和 7 个 `/usa/` 工具。
- 首页、全部工具、404 与新增隐私说明页。
- 统一 OpenAA 正式 Logo、主站蓝色与灰底白卡片、移动端布局。
- 所有 canonical/分享/结构化数据统一 `tools.openaa.com`；sitemap 自动覆盖 44 个可收录页面，不含 404。
- 移除旧全页 HTML、旧 CSS/JS 目录和未完成的重构脚本；历史版本由 git 保存。
- 保留全部旧工具路径、记录键和备份数据格式。

## 验证门槛

`npm run validate` 检查类型、计算和数据存储测试、构建、所有页面本地资源和 sitemap。
`npm run test:e2e` 在手机与桌面验证所有工具页、横向溢出、脚本错误、搜索筛选、计算、DMV、查询降级和记录流程。

## 发布及回滚

在 PR 完成检查后合并 main，由工作流发布。正式域名需逐页抽验；构建成功不等于 DNS/HTTPS 或生产发布成功。
如需回滚，恢复上一版部署产物或 revert 此重构提交并重新部署。不要清理用户 localStorage。历史分支保留，不属于正式发布来源。

- Astro 类型检查无错误或警告。

- 构建生成 45 页；全部 41 个工具网址、图标、脚本、样式、canonical 和 sitemap 本地验证通过。
- 手机（390px）和桌面（1280px）浏览器覆盖全部工具、搜索分类、输入错误、DMV 按钮、模拟查询成功/失败、两种记录工具的保存与导入导出、离线记录及缓存隔离。
